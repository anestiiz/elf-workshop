# Автономное обучение — v42

Рабочий сайт v41 новее исходников в `project/src` (они остановились на v30).
Этот модуль обновляет только актуальные учебные сцены и переходы между ними.
Карта, уровни, подарки, монеты, музыка и сохранения продолжают использовать прежний runtime.

- `TutorialDemo.jsx` — настоящие DOM-элементы: детали, ячейка, игрушка, подарок, корзина и указатель.
- `timeline.mjs` — последовательность сборки и очистки, видимое время и автоматический переход.
- `autonomous-tutorial.css` — оформление указателя и перемещаемых деталей, поддержка reduced motion.
- `build.mjs` — собирает модуль, подключает React текущей игры и заменяет только изолированный компонент
  учебной сцены и добавляет hook перехода в существующую модалку. Хеш исходной сборки проверяется;
  несовместимая новая базовая сборка останавливает обновление.

Из корня репозитория:

```sh
cd project
npm install --package-lock=false
cd ..
node project/active-tutorial/build.mjs
node --test project/active-tutorial/tests/tutorial.test.mjs
```

Публикуются `index.html` и три сгенерированных файла в `assets/`. Исходные файлы v41 сохраняются как
проверенная база для повторной сборки. Запуск `npm run build` внутри старого `project/` откатит поздние
изменения игры, поэтому для обновления обучения используется команда выше.

Первые две сцены проигрываются и переходят дальше сами. «Далее», «Пропустить обучение» и закрытие
сохраняются. На последней карточке «Поехали!» закрывает обучение и оставляет игрока на карте. Свёрнутая вкладка не расходует время
демонстрации. При закрытии или смене шага все обработчики и animation frame освобождаются.
